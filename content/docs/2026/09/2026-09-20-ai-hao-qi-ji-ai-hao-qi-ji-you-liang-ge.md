明天要上班，本周的AI好奇记提前一天。

今早看到的第一个感兴趣话题来自于名叫SPECS的AR（Augmented Reality，增强现实）眼镜。这眼镜可做的事情很多，导航、实时翻译、看电影、听音乐、录像、拍照、打电话等等等等。看过它的介绍文章之后，我多出来的想法有这样两个：

一是或许未来的AR，真能作为手机的额外展示屏？或者直接替代手机？

二是好奇SPECS的实现方式。介绍视频中，与SPECS的交互是可以直接用手指选按钮的，如何做到的呢？全来自于视频识别去匹配？

再看一篇自进化相关文章，看完之后脑子当中一点想法都没有，依然只能记住主题“自进化”。

## **一、GitHub流行趋势**

言归正传，依然回到GitHub本周的流行趋势。我发现现在的自己，对于GitHub上的流行趋势，内心是充满好奇的，每周花一小时找到好用工具再将其用在工作中真不错。

### **1、https://github.com/alibaba/open-code-review**

> Secure, fast, efficient, battle-tested at Alibaba's scale. Hybrid architecture code review tool: deterministic pipelines + LLM Agent, precise line-level comments, built-in multi-language ruleset (NPE, thread-safety, XSS, SQL injection), OpenAI & Anthropic compatible.

阿里开源的一个代码评审工具，看过它的介绍：“Emmm，明天上班之后，如果有时间，试着用用看呢？我那MiniMax的Coding plan买了，已经好几个月没用过了。”

Code review，对当今的写代码，可是越发重要的一环了呢。

### **2、https://github.com/Tencent/WeKnora**

> Open-source LLM knowledge platform: turn raw documents into a queryable RAG, an autonomous reasoning agent, and a self-maintaining Wiki.

关于RAG，前段时间我的感觉是，似乎它越发不受关注了。

这腾讯的框架，是将文档转为可以召回的知识。

### **3、https://github.com/stablyai/orca**

> Orca is the ADE for working with a fleet of parallel agents. Run any coding agent with your own subscription. Available on desktop, mobile and remote runtime.

一个可以将Codex、Claude Code统一管理起来，还支持自己独立的手机端应用，且待我明天（如果有时间的话）也试试。
